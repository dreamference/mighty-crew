# Mighty Crew specification

One document per area, in the house style of Mightling's `specs/` (a header with status, goal and what it builds on; numbered sections; measured results only).

| Document | What it covers |
| --- | --- |
| [DREAMFERENCE_MIGHTY_CREW.md](./DREAMFERENCE_MIGHTY_CREW.md) | The MVP: the problem, the model (crew, role, tree, chat, note, message), the user's day, the chat, the command line, configuration, messaging policy, reboot and recovery, acceptance, non-goals, open questions, the crate as it stands, the first day's lessons with their incidents |
| [DREAMFERENCE_MIGHTY_CREW_GROWTH.md](./DREAMFERENCE_MIGHTY_CREW_GROWTH.md) | How the product spreads, after the MVP: the chat that names its keeper, a repository that carries its crew, the digest, the offline demo, a view for a screen, numbers from the chat, a crew that reads another's chat; each a dated proposal with the line that says it is done |

The prototype the specification was written from is in [`../prototype/`](../prototype/): `session` (the launcher), `session-note` (the chat writer) and `session-chat-hook` (the start-time chat print), as run by hand on 2026-10-10.
