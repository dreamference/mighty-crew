# Mighty Crew specification

One document per area, in the house style of Mightling's `specs/` (a header with status, goal and what it builds on; numbered sections; measured results only).

| Document | What it covers |
| --- | --- |
| [DREAMFERENCE_MIGHTY_CREW.md](./DREAMFERENCE_MIGHTY_CREW.md) | The MVP: the problem, the model (crew, role, tree, board, note, message), the user's day, the board, the command line, configuration, messaging policy, reboot and recovery, acceptance, non-goals, open questions |
